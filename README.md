# SCT_WD_1 — Responsive Landing Page

**Internship task:** SkillCraft Technology — Web Development, Task 01  
**Project:** Nova Studio responsive landing page  
**Built with:** HTML5, CSS3, vanilla JavaScript

## Features
- Fixed navigation bar that remains visible while scrolling.
- Header background, border, and shadow change after scrolling.
- Navigation links respond to hover and highlight the section currently in view.
- Responsive mobile menu with accessible expanded state and Escape-key support.
- Responsive layouts for desktop, tablet, and mobile screens.
- Hero section, services, selected work, about section, contact CTA, and footer.
- Reduced-motion preference support and semantic page sections.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser.
3. For a local development server, you can use VS Code's Live Server extension.

No build step or dependencies are required. Google Fonts are loaded from the internet; the page uses fallback fonts if unavailable.
